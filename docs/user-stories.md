# User Stories

Use the format:

> As a \<user>, I want \<goal> so that \<reason>.

## Story List

1. US-01: As a UEA student I want to import my modules and assessments from a provided data file so I dont have to enter deadlines manually
2. US-02: As a student I want to log indiviual study sessions against specific tasks so that my work contributions actively contribute to the progress of the task
3. US-03: As a Student I want a dashboard that shows my upcoming deadlines overdue tasks so I know everything neccessary at a glance
4. US-04: As a student I want to view my semester on a Gantt chart that highlights different colours for upcoming and overdue tasks so I know when tasks start and end and what needs attention
