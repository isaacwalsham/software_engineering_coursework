# Task 3: Identify major system responsibilities                                                      					User Story No. = US-(N)

 ##   Primary responsibilities of the System (Study Planner):

   ###     School Data migration
    
   Have the ability to import data from user's school including information about module assessments and their deadlines, and automatically sort them into separate sections, with a structure reflecting that of the semester. This reflects upon the requirements of US-01.
            
   ###  Coursework Breakdow
   
   System should grant the user the ability to deconstruct their coursework into separate more manageable tasks to act as milestones. Doing so allows the user to focus on task dependencies.
            
   ###   Tie Study sessions to Tasks to track progress towards Task completion
 
   A further primary function of the system should be to allow the user to assign a label to their study session logs of whichever task the session relates to assist with progress tracking.
            
  ###  Produce visual representations of Coursework tasks, progress and dependencies 
  
  The system should allow the user to better understand their current progress towards coursework completion through mediums such as Gannt Charts which illustrate when throughout the semester specific tasks should be completed, the user's progress towards said tasks (percentage bar within task) and the dependencies of each task that need to be completed before the user can proceed.
            
  ###  Collate progress towards each module
        
   The system should feature a dashboard which collates the total progress for each task of each module, so that the user can see in which modules they need to focus more of their attention. 

   ###  Deadline + Overdue Reminders
        
   User should receive notifications from the system with reminders of tasks due in x days, as well as any tasks that are overdue and in need of immediate attention.
