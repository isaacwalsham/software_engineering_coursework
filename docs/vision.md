# Project Vision

## 1. Background
UEA students often manage multiple modules with overlapping coursework deadlines, exams, and independent study tasks, making effective planning difficult. Generic tools such as calendars and to-do lists do not capture academic dependencies, milestones, or the relationship between time spent studying and real progress. The Study Planner is a web-based application designed to address this gap by providing a structured way to plan, track, and visualise study activities throughout a semester. By combining task planning, progress tracking, and clear visual feedback, the system aims to help students manage workload more effectively and reduce last-minute pressure.

## 2. Project Goals

Enable UEA students to create a semester study plan by importing module, coursework, and deadline data.
Support structured study planning through tasks, milestones, and task dependencies.
Allow students to record study activities and automatically track progress toward task completion.
Provide clear visualisations, including a Gantt chart and dashboard, to improve awareness of deadlines and progress.

## 3. Primary Users & Stakeholders
Primary users: UEA students using the web application to manage their study planning.
Stakeholders: Module organisers (as sources of assessment and deadline information) and the University of East Anglia, as the system owner and potential future adopter.

## 4. Success Criteria

Students can log in and successfully create a semester profile using imported module data.
Tasks, milestones, and dependencies are correctly displayed in the Gantt chart.
Recorded study activities update task progress accurately.
The dashboard correctly highlights completed, upcoming, and missed deadlines.
